# 🍬 Nassau Candy Data Analysis

Sales Analytics • Business Insights • Shipping Optimization

## 📊 Project Overview

This project analyzes the Nassau Candy Distributor dataset to understand sales performance, profitability, shipping behavior, and potential shipping optimization opportunities.

The project combines **Excel dashboard analysis** with **Python-based data analysis** and is designed to demonstrate practical Business/Data Analyst skills.

## 📁 Dataset

- **Records:** 10,194
- **Columns:** 18 original columns
- **Analysis Period:** 2024–2025

## 🚚 Shipping Optimization Analysis

A separate shipping optimization analysis was performed to identify high-value product/state combinations with comparatively high lead times.

The analysis identifies **candidates for further investigation** when evaluating alternative factory assignments.

The dataset does not contain sufficient information about:

- Factory locations
- Factory capacity
- Existing factory assignments
- Actual shipping distances
- Factory-specific operating constraints

Therefore, the analysis identifies **potential candidates for review rather than making a definitive factory relocation decision**.

## 💡 Business Insights

The analysis focuses on identifying:

- High-revenue products
- High-performing regions and states
- Sales and profitability trends
- Shipping-mode performance
- Long lead-time patterns
- Potential shipping optimization opportunities
