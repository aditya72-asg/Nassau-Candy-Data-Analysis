# Nassau Candy Data Analysis

## 📌 Project Overview

This project analyzes Nassau Candy sales data to identify important business insights, sales trends, product performance, and customer purchasing patterns.

The project focuses on data cleaning, exploration, analysis, and visualization to support data-driven business decisions.

## 📂 Dataset

The dataset contains sales-related information from Nassau Candy, including product, sales, customer, and transaction details.

**Dataset file:** `Nassau Candy Distributor.csv`

## 🛠️ Tools & Technologies

- Microsoft Excel
- SQL
- Python
- Power BI

## 🔍 Key Analysis Areas

- Sales performance analysis
- Product-wise sales analysis
- Customer purchasing patterns
- Sales trends
- Revenue analysis
- Identification of top-performing products
- Business insights and recommendations

## 📊 Project Goal

The main objective of this project is to transform raw sales data into meaningful insights that can help businesses understand performance, identify trends, and make better data-driven decisions.
